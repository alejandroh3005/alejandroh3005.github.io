# modelLong

**modelLong** is a publicly available R package I developed to streamline workflow and visualize correlated data from repeated measures (e.g., autocorrelation plots). There is support to run advanced statistical models (e.g., generalized estimating equations). I strongly invite individuals interested in contributing to reach out!

View the [documentation](https://alejandroh3005.github.io/modelLong/index.html). for a comprehensive look at the package, including examples and tutorials.
